第 1 頁 · 封面

🎛️ 調參數 = 調整學習方式

積木上的每個數字，都是「電腦怎麼學習這組資料」的控制開關。

預設值就像一份讀書計畫範本——對多數人都不錯，但沒有人的情況完全一樣。

📌 為什麼要調？

資料難易不同、圖片多寡不同、目標不同（迴歸？圖像分類？物件偵測？）。 調整參數，讓「學習方式」配合你的資料。

🧭 接下來…（章節動線，對照積木欄位順序）

1. 基本設定：類型、訓練主機、資料集、資料同步、模型存放

2. 餵資料的策略：驗證比、擴增、Dropout

3. 電腦怎麼學：模型 → Loss → 學習率(LR) → Epochs → Batch

4. 進階設定：預訓練、微調、DNN 層、優化器、模型輸出

第 2 頁 · 調參數的意義

🎯 類型與訓練主機 Type & Training Host：先決定「做什麼、在哪做」

🎯 類型 (Type)

  • 分類器：這張圖是什麼？（剪刀石頭布、手勢）
  • 偵測器：東西在哪裡？（框出物件位置）
  • 循線：線在左邊還是右邊？（循跡小車）
  • 表格：從表格資料學規律（非圖像）
💡 類型決定訓練方式與推論引擎，要與後面「初始化模型」積木的類型一致。

🖥️ 訓練主機 (Training Host)

  • 本地：用自己的電腦訓練。資料少、模型小時最方便，教學預設。
  • 遠端：送到遠端主機訓練。第一次執行會跳出 SSH 設定。
✅ 教學建議：先用「本地 + 分類器」把整個流程跑通；等資料變多、訓練變慢，再考慮遠端。
第 3 頁 · 類型與訓練主機

🎯 Dataset (資料集)

📂 放哪裡、長這樣

專案目錄/dataset/classifier_dataset(資料集名稱) /scissors 剪刀 138 張 /rock 石頭 108 張 /paper 布 124 張 /none 只有背景 32 張

每個子資料夾 = 一個分類，照片放在對應資料夾。

📖 比喻：教科書

資料集就像「章節清晰的教科書」。

沒分章節、內容少，很難讀出重點。

⚠️ 每個分類至少 5 張，建議 20–100 張。
若數量不平均（30 vs 500）——這叫類別不平衡 (class imbalance)——樣本多的分類會主導Loss(後述)，訓練出來的模型容易偏心。
第 4 頁 · Dataset (資料集)

🔄 資料同步與模型存放 Data Sync & Model Folder

🔄 資料同步 (Data Sync)

僅在訓練主機 = 遠端時生效：決定本地資料集要不要送上遠端主機。

  • 智慧（預設）：資料有變更才上傳——最快、最省流量
  • 每次：每次訓練都完整上傳——最保險但最慢
  • 略過：不上傳，直接用遠端主機上既有的資料集
💡 訓練主機 = 本地時，此欄位沒有作用，保持預設即可。

📦 模型存放 (Model Folder)

  • 訓練好的模型會存到這個資料夾。
  • 自動從資料集名稱帶出（dataset/xxx → model/xxx），唯讀、不必手改。
  • 之後的推論積木「初始化模型」就是到這裡找模型檔。
✅ 一套流程自動串好：資料集名稱 → 模型資料夾 → 推論載入，全程不用自己輸入路徑。
第 5 頁 · 資料同步與模型存放

✂️ 驗證比 Validation Split (驗證集比例)：留一份「模擬考」

📖 比喻：讀書 ≠ 會考試

不能拿「讀過的題目」考自己——那只是背答案。
要留一部分不曾拿來讀的例題當模擬考，才知道「真的懂了沒」。

Validation Split (驗證比) = 從資料中抽出當作模擬考的比例（預設 20%）。

🧪 實務：分層抽樣

光「隨機抽 20%」有好有壞——若某分類很少，可能被抽光，模擬考就沒考到它。
所以 Cocoya 用分層抽樣 (Stratified Split)：每個分類各自抽出固定比例，保證公平。

找到 4 個分類: none: 32 張 / paper: 124 張 / rock: 108 張 / scissors: 138 張 分層抽樣 (stratified split): none: train 26 / val 6 paper: train 99 / val 25 rock: train 86 / val 22 scissors: train 110 / val 28
💡 調校後果：變大（0.5）= 讀書資料變少、模擬考更嚴；變小（0.1）= 讀書多、但考得不夠。預設 0.2 平衡。
第 6 頁 · Validation Split (驗證比) · 分層抽樣

🪞 擴增 Augmentation (資料擴增)：把一份資料「舉一反三」

📖 比喻：變體練習

同一張課本圖，練習時轉一轉、翻一面、放大縮小——看了「不同版本」的同一題。

這讓模型學會：「不管剪刀是橫的、斜的、近的、遠的，都是剪刀。」

Augmentation (擴增) 開啟後，每次餵進去的是原始資料的輕微變體，等於免費多了好多張練習題。

⚖️ 調校後果

選項後果
✔ 開啟（預設）資料多樣性↑ → 更強健、不易過擬合，多一點點訓練時間
✖ 關閉只能重複看原圖，容易背圖；小資料特別容易過擬合
✅ 資料很少時強烈建議開啟；除非你刻意要原圖訓練，否則保持開啟。
第 7 頁 · Augmentation (資料擴增)

🎲 Dropout 隨機遺忘率：強迫「換個思路想」

🧠 問題：死背／過度依賴

模型可能養成依賴某條路徑的壞習慣——記得 3 條規律就答對，但要是考的另 1 條就全錯。

這就像只會一種解法，考試題目換個樣子就卡住。

🎲 解法：Dropout

訓練時隨機關閉一部分神經元，逼它不用原本那條路、另找路徑解題。

比喻：把「代數」看成「幾何」，用不同的思考方式獨立得出答案 → 學會備份方案。

⚖️ 調校後果

數值後果
0（關閉）沒有隨機遺忘，小資料易過擬合（專背起來）
0.2（預設）輕度約束，訓練時斷 2 成神經元 → 多數情況的好平衡
太大 (0.9)神經元被關太多，根本學不起來（廢掉太多路徑）

💡 看到「模擬考好、準確卻停滯」或明顯死背時，可以略增；初學者保持 0.2 即可。

第 8 頁 · Dropout (隨機遺忘率)

🔮 模型到底是什麼？

模型 = 網路架構(演算法) + 參數〔權重 (Weight) + 偏置 (Bias)〕，一套數學應對法則。

訓練 = 從資料裡找出這組參數；之後拿它套用在新資料上做預測 (Prediction)。

📈 最簡單的例子：迴歸線

想用 x 預測 y，可假設一條線 ŷ = w·x + b

w（權重）控制線的斜率，b（偏置）控制線的高度。找出好的 w、b = 訓練模型。

🧠 比喻：大腦的「應對法則」

辨識「剪刀」不靠死背每一張圖，而是學會一組規則：「兩根細長、交叉」→ 剪刀。

這個規則，就是用一組一組的 w、b 數值儲存在模型裡——這就是可以帶走的知識。

💡 224×224 的圖將每個像素先正規化成 0～1 的數字後，輸入模型，經過層層運算，最後輸出「它是某分類的機率」。
第 9 頁 · 模型：權重、偏置與預測

📉 Loss Function (損失函數)：與答案「差多少」？

🎯 預測有正中靶心(答案)嗎？

🧮 損失 = 預測與實際的差距

對每一筆輸入的資料，模型都猜一個答案。預測與答案差多少？把它量化成分數，就是Loss (損失)。

常用 MSE（Mean Squared Error，均方誤差）計算迴歸的損失：

MSE = 1n nΣi=1 ( ŷi − yi )²

其中 ŷi = 模型預測值、yi = 實際值、n = 資料筆數。也就是「平均( 預測值 − 實際值 )²」。


💡 分類任務（如剪刀石頭布）的損失用「交叉熵 (Cross-Entropy)」，第 10 頁會用簡單的方式說明。

總之：Loss 越小 = 對目前資料猜得越準。

第 10 頁 · 損失函數

🪞 MSE 的二次曲線：偏離愈多、罰愈重

把 (ŷ − y) 記為 e (誤差)，MSE 的每一筆就是 L = e2 —— 一條開口向上的拋物線（二次函數）。

🎯 從曲線看三件事

  • 猜錯是平方級的罰：差 1 罰 1、差 2 罰 4、差 4 罰 16——偏離越遠，代價暴漲。
  • 左圖只是針對單一資料點，事實上我們要考慮 所有資料的 L 加總平均，所以曲線會有所變形。
  • 谷底 = 曲線上 L 最小的位置。真實資料有雜訊，通常不可能每一筆都完全猜中（e = 0）——訓練要走到的是「平均損失」最低的谷底。
💡 訓練的終極目標：把所有資料的 L 加總平均，沿著這條拋物線（其實是高維的「山谷」，目前先以線性迴歸模型來想像。）一路往最低點走，找到最貼近資料規律的 w、b。
💡 因為 e = (ŷ − y)，而 ŷ = wx + b ，調整 w,b 就可以調整 e ，進而改變 L 。訓練模型的過程，就是想辦法一步步調整 w,b 來讓 L 沿曲線降到谷底(最小值) 。
第 11 頁 · 二次 Loss 曲線

🎲 Cross-Entropy (交叉熵，分類任務的損失)：罰「錯得有自信」

🧠 分類任務怎麼給分？

分類任務中，模型不是猜一個數字，而是對每個分類給一個機率，合計為 100%。
例如輸入一張剪刀照片，模型可能說：

剪刀 72% 石頭 18% 布 10% 答案：剪刀 ✓

分類任務的 Loss 使用交叉熵的概念：只看「正確答案那個分類」的機率有多高，用 L = −log(p) 換算成分數：

  • p 愈接近 1（猜對且有自信）→ L 愈接近 0
  • p 愈接近 0（該猜對的沒把握）→ L 暴增到非常大

⚖️ 三種表現，罰多少？

模型的表現答案的機率 p交叉熵 L = −log(p)
猜對，而且很有自信0.9很小（約 0.11）
猜對，但信心不足0.4中等（約 0.92）
猜錯，還錯得很有自信0.05非常大（約 3.0）

（在電腦科學上，log 通常以 e 為底）

✅ 和 MSE 的精神相通：MSE 罰「偏得遠」，交叉熵罰「錯得有自信」。兩者都在教模型「對自己的答案要又準又有把握」。
💡 迴歸任務用 MSE，分類任務用交叉熵。
訓練曲線上的 loss，用的就是與任務對應的那一種。
第 12 頁 · 交叉熵 (Cross-Entropy)

📏 Learning Rate (學習率)：依所在位置(斜率)向下修正時的倍率

還記得大家要「把 Loss 愈推愈低」？做法是沿著斜坡往下走（梯度下降 Gradient Descent）。
Learning Rate (學習率, LR) 就是「依斜率走一步的倍率」——實際步長 = LR × 當下斜率：坡陡走大步、近谷底斜率小自動縮步。

⛰️ 學習率：太大 vs 剛好

⚖️ 調校後果

數值下場比喻
太大
(0.1～1)		一步跨過谷底，來回搖擺不穩：Loss 曲線震盪劇烈，甚至不降反升修正太用力，錯一次改太多
剛好
(0.001)		每次穩定修正一點，收斂到低點：Loss 曲線平滑穩定下降看出小考錯在哪，重點修正
太小
(0.0001)		收斂極慢，很久才接近谷底：Loss 曲線降得極慢、幾乎不動每個字都讀、速度太慢
✅ 預設 0.001，不確定就先不動。
🔍 要調時，看 loss 曲線的走向決定：
‧ 曲線震盪劇烈或不降反升 → LR 太大，調小
‧ 曲線降得極慢、幾乎不動 → LR 太小，調大
‧ 曲線平滑穩定下降 → LR 剛好，不用動
💡 一次只改 LR 一個參數，重跑再看曲線。
第 13 頁 · Learning Rate (學習率)

🔄 Epochs 訓練輪數 (Epoch)：整本書重讀幾遍？

📖 定義

Epoch (輪) = 把整份訓練資料從頭到尾讀一遍。

Epochs = 讀幾遍（預設 20）。電腦每一次輪，都把所有資料拿去更新權重一次。

⚖️ 讀太少 vs 讀太多

份數後果比喻
太少
(1～5)		還沒學到規律（欠擬合），Loss 還是很高讀一遍就考試 → 全忘
剛好
(20)		學到規律，模擬考也有好表現反覆複習到掌握
太多
(1000)		把資料「背」起來（過擬合），新資料反而變差背好答案，考題一變就卡

📺 實際輸出：開始訓練 (20 epochs) → Epoch 1/20 → Epoch 2/20 …每輪結束都會報一次 accuracy 與 loss。

💡 看「模擬考（val）分數」是否還在上升、還是停滯了？停了就代表多讀只是浪費時間。

第 14 頁 · Epochs (訓練輪數)

📦 Batch Size 批次大小：一次「小考」考幾題？

🪜 Epoch 與 Batch 的關係

一整輪資料 = 一本課本。但電腦不一口氣讀完整本，而是拆成一小批一小批（Batch）。

每一輪 (Epoch) = 分批跑完整份資料
Batch 大小 = 每批處理幾張（預設 32）

每讀完一個 Batch，就做一次「小考」：算當下 accuracy、loss，並據此小幅更新權重。

⚖️ 調校後果

大小下場
小
(1～16)		小考頻率高，修正快但有雜音；每輪迴圈多 → 稍慢
中
(32) 預設		穩定與速度平衡
大
(128～512)		段考式，穩定但修正遲緩；需更多記憶體

💡 記憶體不足（Out of Memory）就調小 Batch；想更穩就試著調大。

📺 一次 Epoch 內部：1/11 → 2/11 → … → 11/11（共 11 個 Batch），每一小段都是一次小考，結尾顯示該輪總成績：

Epoch 1/5 1/11 ━━━━━━━━━━━━━━━━━━ 48s 5s/step - accuracy: 0.0938 - loss: 1.6940 2/11 ━━━━━━━━━━━━━━━━━━ 6s 686ms/step - accuracy: 0.1406 - loss: 1.6701 11/11 ━━━━━━━━━━━━━━━━━━ 13s 826ms/step - accuracy: 0.4829 - loss: 0.9899 - val_accuracy: 0.6667 - val_loss: 0.7169

看！accuracy 一路從 0.09 → 0.48 爬升，loss 一路下降 —— 每批小考後都在進步。

第 15 頁 · Batch Size (批次大小)

🏗️ 預訓練 Backbone (骨幹網路)：站在巨人肩上

Backbone = 負責「看圖抓特徵」的網路骨架。它已用上千萬張圖預先訓練（預訓練，前備知識），懂得邊緣、形狀、紋理——你只要在它上面「補習」自己的類別。（積木欄位即顯示為「預訓練:」）

比喻：站在巨人肩上，不用從 0 發明怎麼「看」，只要微調它來認你的東西。

MobileNetV2 預設

輕量快速，體積小、適合入門與 MCU。

→ 教學預設首選。

EfficientNetB0

效率平衡，準度與運算量折衷。

→ 想更準一點的進階選擇。

ResNet50

深而重，特徵強但慢、耗記憶體。

→ 資料多、資源足時使用。

⚠️ 圖片固定 224×224，是為了配合 Backbone 的預訓練輸入。換預訓練模型＝換一副「眼睛」，特徵取向不同。
第 16 頁 · Backbone (骨幹網路) · 預訓練

🔓 微調 Fine-tune：把「別人的筆記」改成自己的

📖 預設：骨架「凍」著

通常保持預訓練的「眼睛」不動，只訓練後面的思考層——又快又穩，資料少也安全。

這像「用別人整理好的筆記，只補自己的重點」。

🔓 開啟 Fine-tune

解凍整個骨幹，也一齊微調它的權重 → 更貼合你的資料。

像「把整本筆記重寫成自己的話」。更準，但需要更多資料，否則把預訓練知識也搞壞。

⚖️ 調校後果：

◾ 關閉（預設）：快、穩、資料少也 OK

◾ 開啟：準度可能更高，但易過擬合、訓練更久

⚠️ 資料少（每類 < 20 張）建議維持預設關閉；資料多再嘗試開啟。
第 17 頁 · Fine-tune (微調)

🧠 DNN 層 DNN Layers (自訂隱藏層)：多幾層「思考」？

在骨幹抓完特徵後，後面可以加幾層「思考層」（隱藏層 Hidden Layers）來做最終判斷。
格式是逗號分隔的神經元數，如 128,64（兩層）：先 128 顆廣泛想，再縮到 64 顆聚焦結論。

輸入（骨幹特徵）→ 128 → 64 → 輸出（每個分類的機率）

💡 層越多越能表達複雜規律，但越易過擬合、越慢、越吃記憶體。留空 = 跳過思考層直接輸出。初學者用預設 128,64 即可。
第 18 頁 · DNN Layers (自訂隱藏層)

⚙️ 優化器 Optimizer (優化器)：讀書的策略

🔄 它做什麼？

決定「這次該修多少」——怎麼把權重從舊值一步步推到更低的 Loss。

基本公式（以 SGD 為例）：

新權重 = 舊權重 − 學習率 × 當下斜率 (Gradient)

注意：固定的是學習率。步長 = 學習率 × 當下斜率；斜率大步伐大（陡坡快跑），靠近谷底斜率小步伐自動縮小（精細修正）。

📊 三種策略

優化器特性
Adam 預設記憶過去幾次修正的方向與幅度，動態調整學習率與步伐 → 聰明、收斂快、普遍好用
SGD固定學習率，步長全靠當下斜率 → 穩健踏實，但收斂較慢、易卡
RMSprop對每個權重個別調整步伐（除以歷史根均方）→ 對不齊的梯度較友善
✅ 初學者用預設 Adam，幾乎不用改。

  • 資料集：課本要整理好

  • 預訓練：站在巨人肩上（MobileNetV2）
  • 優化器：讀書策略（Adam）
  • DNN 層：要多幾層思考（128,64）
  • 微調：把別人的筆記改成自己的（關）
  • 輸出格式：要交什麼成品（none 先看）
