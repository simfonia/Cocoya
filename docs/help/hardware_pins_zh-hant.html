開發板腳位說明 (Pinout Reference)

歡迎使用 Cocoya 硬體控制積木！不同的開發板擁有不同的腳位配置，請參考下方的圖表與說明進行開發。

1. Maker Pi RP2040

這款開發板最大的特色是板子表面的標註非常清晰：每個藍色 LED 與排針旁邊都直接印有對應的腳位名稱（例如 GP0, GP1...）。以下對照整理自 Cytron 官方 MAKER-PI-RP2040 Datasheet Rev 1.2（Table 1）。

提示： 在 Cocoya 中請先放上 初始化開發板 積木並選擇 Maker Pi RP2040；腳位下拉會依這塊板列出下表腳位（含 M1A、Servo、Button 等功能提示）。
腳位板載功能
GP8 / GP9直流馬達 M1A / M1B（正轉 / 反轉）
GP10 / GP11直流馬達 M2A / M2B
GP12 ~ GP154 組 RC 伺服馬達訊號腳（V+ 等於電源電壓）
GP18板載 WS2812B RGB LED（NeoPixel）
GP20 / GP21可程式按鈕 1 / 2
GP22Piezo 蜂鳴器（可播放音階與旋律）
Grove 埠腳位複用功能
1GP0 / GP1PWM0-A/B、SPI0、I2C0 (SDA/SCL)、UART0 (TX/RX)
2GP2 / GP3PWM1-A/B、SPI0 (SCK/SDO)、I2C1 (SDA/SCL)
3GP4 / GP5PWM2-A/B、SPI0、I2C0 (SDA/SCL)、UART1 (TX/RX)
4GP16 / GP17PWM0-A/B、SPI0、I2C0 (SDA/SCL)、UART0 (TX/RX)
5GP6 / GP26GP6：PWM3-A、SPI0 (SCK)、I2C1；GP26：ADC0（A0）
6GP26 / GP27GP26：ADC0（A0）；GP27：ADC1（A1）、PWM5-B、I2C1
7GP7 / GP28GP7：PWM3-B、SPI0 (SDO)、I2C1；GP28：ADC2（A2）
  • 類比讀入 (ADC)： GP26 = ADC0、GP27 = ADC1、GP28 = ADC2。
  • GPIO 狀態 LED： Grove 埠上的每個 GPIO 都有一顆藍色指示燈（腳位為高電位時亮）。
  • 電源： 馬達與伺服的輸出電壓等於輸入電壓（僅接 USB 時約 VUSB − 0.4V）。

3. XIAO ESP32-S3 Sense

XIAO S3 體積精巧，腳位採用 D0, D1... 命名。請參考下方的複用功能對照表：

腳位 (Pin) 主要功能 備註 (Multiplexing)
D0 ~ D3 Digital, ADC, PWM 通用腳位，支援類比讀入。
D4 / D5 Digital, ADC, I2C D4 為 SDA, D5 為 SCL。
D6 / D7 Digital, UART D6 為 TX, D7 為 RX。
D8 ~ D10 Digital, ADC, PWM 通用腳位，支援類比讀入。
重要： ESP32-S3 幾乎所有腳位都支援 PWM，但請優先使用 D0~D3 與 D8~D10 進行一般感測器連接。更詳細的腳位複用資訊請參考 Seeed Studio 官方 Wiki。
