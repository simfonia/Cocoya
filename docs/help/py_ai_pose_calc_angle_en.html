📐 Angle of 3 Points (py_ai_pose_calc_angle)

Description

Pass 3 coordinate points A, B, C (x, y) in order and returns the angle at vertex B.
Accepts Tuple (x, y) inputs — wire it directly to blocks that output tuples such as get_landmark_xy or get_bbox_center.

Type

TypeRangeMeaning
Interior0°–180°Default. Standard vertex angle.
Exterior180°–360°360° − Interior.
Signed−180°~+180°Directional: positive = CCW, negative = CW.

Direction Rule (±) ⚠️ Key

With vertex B, the sign of the Signed angle is determined by the rotation from ray BA (toward A) to ray BC (toward C):

  • Positive (+) = Counterclockwise (CCW) — from A's direction to C's direction, CCW is positive.
  • Negative (−) = Clockwise (CW) — from A's direction to C's direction, CW is negative.
Example: A=(0,1)  B=(0,0)  C=(1,0)
  BA points "up", BC points "right"
  up→right is clockwise 90°  →  signed = −90°  →  interior = |−90| = 90°
Coordinate-system note: OpenCV pixel coords have y pointing down, so on-screen rotation appears reversed vs. math coords (y up). The numerical rule is always consistent: positive = CCW from ray A to ray C.

Relationships: Interior = |Signed| · Exterior = 360° − Interior.

Formula

# a, b, c: (x, y) tuples; vertex is b
v1 = (a[0]-b[0], a[1]-b[1])   # ray BA (toward a)
v2 = (c[0]-b[0], c[1]-b[1])   # ray BC (toward c)
dot   = v1.x*v2.x + v1.y*v2.y
cross = v1.x*v2.y - v1.y*v2.x
signed   = degrees(atan2(cross, dot))   # -180..180
interior = abs(signed)                  # 0..180
exterior = 360 - interior               # 180..360

Usage Example

# Elbow joint angle (A=shoulder 11, B=elbow 13, C=wrist 15)
angle = cocoya_calc_angle_3pts(shoulder_xy, elbow_xy, wrist_xy)        # interior
turn  = cocoya_calc_angle_3pts(p1, p2, p3, mode='signed')               # directional
