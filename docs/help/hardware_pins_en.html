Board Pinout Reference

Welcome to Cocoya Hardware Control! Different development boards have different pin configurations. Please refer to the charts below for wiring.

1. Maker Pi RP2040

The best feature of this board is that labels are clearly printed on the board surface: each blue LED and header has its pin name (e.g., GP0, GP1...) printed right next to it. The tables below follow the official Cytron MAKER-PI-RP2040 Datasheet Rev 1.2 (Table 1).

Tip: In Cocoya, place the Board Init block and select Maker Pi RP2040 first; the pin dropdown then lists the pins below (with hints such as M1A, Servo and Button).
PinOnboard function
GP8 / GP9DC motor M1A / M1B (forward / backward)
GP10 / GP11DC motor M2A / M2B
GP12 ~ GP15Signal pins of 4 RC servos (V+ equals the power source voltage)
GP18Onboard WS2812B RGB LED (NeoPixel)
GP20 / GP21Programmable buttons 1 / 2
GP22Piezo buzzer (tones and melodies)
Grove portPinsMultiplexed functions
1GP0 / GP1PWM0-A/B, SPI0, I2C0 (SDA/SCL), UART0 (TX/RX)
2GP2 / GP3PWM1-A/B, SPI0 (SCK/SDO), I2C1 (SDA/SCL)
3GP4 / GP5PWM2-A/B, SPI0, I2C0 (SDA/SCL), UART1 (TX/RX)
4GP16 / GP17PWM0-A/B, SPI0, I2C0 (SDA/SCL), UART0 (TX/RX)
5GP6 / GP26GP6: PWM3-A, SPI0 (SCK), I2C1; GP26: ADC0 (A0)
6GP26 / GP27GP26: ADC0 (A0); GP27: ADC1 (A1), PWM5-B, I2C1
7GP7 / GP28GP7: PWM3-B, SPI0 (SDO), I2C1; GP28: ADC2 (A2)
  • Analog In (ADC): GP26 = ADC0, GP27 = ADC1, GP28 = ADC2.
  • GPIO status LEDs: every GPIO on the Grove ports has a blue indicator LED (lit when the pin is high).
  • Power: motor and servo output voltage equals the power source voltage (about VUSB - 0.4V when powered by USB only).

3. XIAO ESP32-S3 Sense

XIAO S3 is compact and uses D0, D1... as pin names. Please refer to the multiplexing table below:

Pin Main Functions Notes (Multiplexing)
D0 ~ D3 Digital, ADC, PWM General purpose pins with Analog In.
D4 / D5 Digital, ADC, I2C D4 is SDA, D5 is SCL.
D6 / D7 Digital, UART D6 is TX, D7 is RX.
D8 ~ D10 Digital, ADC, PWM General purpose pins with Analog In.
Important: Most pins on ESP32-S3 support PWM, but please prioritize D0~D3 and D8~D10 for general sensor connections. For more detailed pin multiplexing information, please refer to the Seeed Studio Official Wiki.
