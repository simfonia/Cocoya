🦉AI Training Block (py_ai_train_run)

What it does

Trains an AI model from a dataset and produces model files for later inference (prediction).

Supports four task types: image classification, object detection, line following, tabular data. Training can run locally or on a remote host.

Training output files

After training, the model folder contains:

  • *.tflite — quantized model (for MCU or Edge TPU)
  • *_f32.tflite — Float32 model (for PC-side Python inference)
  • *.keras — Keras native model file
  • *_labels.txt — class label mapping
  • *_training_report.html — training report (curves & stats)
  • *_training_history.json — training history (JSON)
  • *_training_curve.png — Loss/Accuracy curves

Notes

✅ Images are fixed at 224×224, matching the ImageNet pretrained input of MobileNetV2.
✅ The validation set doubles as the final evaluation; no separate test set. Educational datasets are small, so a three-way split would starve each set.
⚠️ Each class needs at least 5 images; 20–100 images per class is recommended.
⚠️ Avoid non-ASCII characters in paths to prevent environment-specific errors.
