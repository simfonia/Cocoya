📏 取得循線線段積木 (py_ai_get_line)

功能說明

從循線（line_follower）推論結果中提取線段的兩個端點。

輸入：推論結果（py_ai_model_predict 的輸出，需為 line_follower 類型）

輸出：Tuple (x1, y1, x2, y2) — 兩端點的歸一化比例座標（0~1，與資料集標註同一座標系）。

為什麼有兩個端點？

Cocoya 的循線標註是「起點 → 終點」兩點（Dataset Manager 的線段標註），訓練模板（line_follower_train.py）以線段端點回歸（Dense(4)）輸出 4 個值，因此模型同時提供：

  • 近端（畫面上 Y 較大者）：可用來判斷車子目前偏離線多少（橫向誤差）
  • 遠端：可用來判斷線往哪裡彎（方向／預測）

兩者搭配即可做出「不切西瓜」的循跡控制（P 項來自近端偏移、D 項來自兩點連線的角度）。

使用範例

result = predict(frame) # 推論
x1, y1, x2, y2 = get_line(result) # 解包兩端點
cv2.line(frame, (int(x1*w), int(y1*h)), (int(x2*w), int(y2*h)), (0, 255, 0), 3) # 畫線
💡 此積木僅適用於「循線 (line_follower)」任務類型。若只想取單一座標值，請使用「取得循線線段的 ⋯」積木。
