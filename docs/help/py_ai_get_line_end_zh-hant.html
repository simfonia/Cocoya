📐 取得循線線段的端點積木 (py_ai_get_line_end)

功能說明

取得線段單一端點的座標值（單一數字），方便直接餵給數學積木做運算。

輸入：推論結果（py_ai_model_predict 的輸出，需為 line_follower 類型）＋ 端點選項

輸出：數字（0~1 比例座標；取不到時回傳 0.0）

  • 端點1 X / 端點1 Y：標註時第一個點擊的端點
  • 端點2 X / 端點2 Y：標註時第二個點擊的端點

端點1 是「近端」嗎？

不一定。端點1/2 只代表標註時的點擊順序。若要判斷「哪一端離車比較近」，請比較兩者的 Y：Y 較大者（畫面上較下方）就是近端。這也是「取得循線橫向偏移」與「取得循線方向角」兩個積木內部採用的規則。

使用範例

result = predict(frame)
x1 = get_line_end(result, 端點1 X)
y1 = get_line_end(result, 端點1 Y)
x2 = get_line_end(result, 端點2 X)
y2 = get_line_end(result, 端點2 Y)
# 自行計算斜率或畫自訂圖形
💡 若只是要做循跡控制，建議直接使用「取得循線橫向偏移」與「取得循線方向角」兩個積木，公式已內建。
