🛡️ Try/Except 例外處理積木 (py_try_except)

功能說明

嘗試執行一段程式碼，當發生指定的例外（錯誤）時，執行例外處理邏輯。

這讓您的程式能夠優雅地處理錯誤，不會因為意外狀況而直接崩潰。

使用方式

  1. 將要保護的程式放入 try 區塊
  2. 從下拉選單選擇要捕捉的例外型別
  3. 將例外發生時要執行的程式放入 except 區塊

例外型別說明

例外型別說明常見情境
Exception捕捉所有例外（最通用）不確定會發生何種錯誤
ValueError數值錯誤字串轉數字失敗
TypeError型別錯誤對錯誤型別進行操作
OSError系統/IO錯誤檔案不存在、無法開啟
IndexError索引錯誤列表索引超出範圍
KeyError鍵值錯誤字典中找不到指定的鍵
ZeroDivisionError除以零錯誤數學運算中除以零

使用範例

try:
    result = 10 / 0
except ZeroDivisionError:
    print("不能除以零！")
✅ 此積木在 PC 模式和 MicroPython 模式下都可使用。
💡 例外處理是撰寫強健程式的重要技巧，建議在可能發生錯誤的地方使用。
