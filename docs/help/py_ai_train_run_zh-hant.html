🦉AI訓練積木 (py_ai_train_run)

功能說明

執行 AI 模型訓練。從資料集學習並產出模型檔案，可用於後續的推論（預測）。

支援四種任務類型：圖像分類、物件偵測、循線偵測、表格資料；可在本地或遠端主機訓練。

基本參數

欄位說明預設值
類型 (Type)任務類型：分類器 / 偵測器 / 循線 / 表格。決定訓練模板與推論引擎，需與「初始化模型」積木的類型一致。分類器
訓練主機 (Training host)訓練在哪裡執行：本地（自己的電腦）或遠端（透過 SSH 送到遠端主機）。選遠端時第一次執行會跳出 SSH 設定。本地
資料集 (Dataset)訓練資料所在資料夾路徑。每個子資料夾代表一個分類。支援相對/絕對路徑，Windows 建議使用正斜線。dataset/classifier_dataset
資料同步 (Data sync)僅訓練主機=遠端時生效：智慧（有變更才上傳）/ 每次（全部上傳）/ 略過（使用遠端既有資料集）。智慧
模型存放 (Model folder)模型檔案的輸出資料夾。唯讀，自動從資料集名稱帶出（dataset/xxx → model/xxx），不必手改。model/資料集名稱
驗證比 (Val Split)驗證集比例。從資料集中分層抽樣分割多少比例作為驗證用。0.2 (20%)
擴增 (Aug)是否啟用資料擴增。自動對圖片進行翻轉/旋轉/縮放等變換。✔ 啟用
Dropout隨機丟棄率。防止過擬合，訓練時隨機丟棄部分神經元。0.2 (20%)
LR (Learning Rate)學習率。控制每次更新的步長。看 loss 曲線調整：震盪不降反升=太大；降得極慢=太小；平滑穩定下降=剛好。0.001
Epochs訓練輪數。越多代表學習越久，但過多可能導致過擬合。20
Batch批次大小。每次更新權重時同時處理的圖片張數。32

進階參數

欄位說明預設值
預訓練 (Pretrained)選用哪個預訓練的骨幹網路（Backbone）：MobileNetV2（輕量快速）/ EfficientNetB0（效率平衡）/ ResNet50（深而重）。MobileNetV2
微調 (Fine-tune)是否解凍預訓練骨幹進行微調。可提升準確率但需更多資料。☐ 停用
DNN 層 (DNN Layers)自訂隱藏層。逗號分隔神經元數，如 "128,64" 表示兩層。
輸入層（GlobalAveragePooling）與輸出層（Softmax）為自動設定，
使用者只需指定中間隱藏層即可。留空則跳過隱藏層直接到輸出。		128,64
優化器 (Optimizer)優化器。選擇 Adam、SGD 或 RMSprop。Adam
模型輸出 (Model output)訓練完成後要產出哪些檔案：無（僅觀察訓練成績）/ 量化 TFLite (int8) / Float32 TFLite / Keras / 量化 + Float32 / 全部。建議先用「無」調好參數，再正式產出。無
💡 不熟悉這些參數的初學者，保留預設值即可獲得良好訓練結果。
💡 各欄位的可輸入範圍與建議值，見下方「數值參數建議範圍」。

訓練輸出檔案

訓練完成後，在模型輸出資料夾中會產生：

  • *.tflite — 量化模型檔案（用於 MCU 或 Edge TPU）
  • *_f32.tflite — Float32 模型檔案（用於 PC 端 Python 推論）
  • *.keras — Keras 原始模型檔案
  • *_labels.txt — 分類標籤對照表
  • *_training_report.html — 訓練報告（含曲線圖與統計）
  • *_training_history.json — 訓練歷史資料（JSON 格式）
  • *_training_curve.png — Loss/Accuracy 曲線圖

注意事項

✅ 圖片尺寸固定為 224×224，與 MobileNetV2 的 ImageNet 預訓練權重綁定。
✅ 驗證集（Validation Set）同時作為最終模型評估，不另設測試集。原因是教育場景資料量較小，三分割會導致各集合樣本不足，且初學者無需區分驗證/測試的複雜概念。
⚠️ 每個分類至少需要 5 張以上圖片，建議每個分類 20-100 張。
⚠️ 路徑中請避免使用中文字元，以免部分環境報錯。
