🛡️ Try/Except Block (py_try_except)

Description

Try to execute code, and run exception handling when the specified exception occurs.

This allows your program to handle errors gracefully without crashing.

How to Use

  1. Place the code to protect in the try section
  2. Select the exception type from the dropdown
  3. Place the error handling code in the except section

Exception Types

TypeDescriptionCommon Scenario
ExceptionCatch all exceptions (most general)Unknown error type
ValueErrorValue errorString to number conversion fails
TypeErrorType errorOperation on wrong type
OSErrorSystem/IO errorFile not found, cannot open
IndexErrorIndex errorList index out of range
KeyErrorKey errorKey not found in dictionary
ZeroDivisionErrorDivision by zeroMath operation divides by zero

Example

try:
    result = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero!")
✅ Works in both PC and MicroPython modes.
💡 Exception handling is an important technique for writing robust programs.
