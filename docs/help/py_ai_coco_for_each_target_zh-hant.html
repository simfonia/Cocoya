🔍 走訪目標物件 (py_ai_coco_for_each_target)

完整說明見 COCO 偵測主頁。

功能說明

使用 MediaPipe Tasks 的 EfficientDet-Lite0 預訓練模型，直接辨識 COCO 資料集的 80 種物件（人、手機、杯子、書本等），不需自己訓練。

高階封裝隱藏了 mp.Image 包裝、VIDEO 模式 timestamp 遞增、categories／bounding_box 物件圖操作；學生只需三步：初始化 → 偵測 → 走訪目標。

積木一覽

積木說明
初始化 COCO 偵測器 (py_ai_coco_init)載入 .tflite 模型；全域信心度建議設低（如 0.2），各物件精確門檻由走訪積木的字典決定。放全域定義區。
執行 COCO 偵測 (py_ai_coco_detect)輸入 frame，自動做 BGR→RGB、mp.Image 包裝、timestamp 遞增、detect_for_video，存入結果變數。
走訪目標物件 (py_ai_coco_for_each_target)輸入偵測結果＋目標字典（如 {"person": 0.5}）。自動跳過：空分類、標籤為空、非目標、信心不足。通過者進迴圈本體。
目標欄位 (py_ai_coco_target_field)只能用在走訪迴圈內。讀取 label、score、x、y、w、h。
釋放偵測器 (py_ai_coco_close)程式結束前釋放資源（detector.close()）。

使用流程

# 全域定義區
init COCO 模型 "model/efficientdet_lite0.tflite"

# 主迴圈
while True:
    ret, frame = cap.read()
    coco_result = detect(frame)
    for each target in coco_result matching TARGET_OBJECTS:
        draw rect (x, y) → (x+w, y+h)
        draw text "label: score"

注意事項

✅ 標籤是英文（如 "cell phone"），字典的鍵必須用英文；中文顯示可用另一個英文→中文對照字典。
⚠️ 迴圈變數（_coco_label 等）為固定命名，不可巢狀兩層走訪積木。
⚠️ VIDEO 模式的 timestamp 由 detect 積木自動遞增，不可手動改 _coco_timestamp_ms。
