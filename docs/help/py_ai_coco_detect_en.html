🔍 Run COCO detection (py_ai_coco_detect)

See COCO main page.

What it does

Uses the MediaPipe Tasks EfficientDet-Lite0 pretrained model to recognize 80 COCO objects (person, cell phone, cup, book, ...) with no training required.

The blocks hide mp.Image wrapping, VIDEO-mode timestamp increments and the categories / bounding_box object graph. Students only do three steps: init → detect → for-each-target.

Blocks

BlockDescription
Init COCO detector (py_ai_coco_init)Loads the .tflite model. Keep the global threshold low (e.g. 0.2); per-object thresholds come from the for-each target dict. Place in the Global Definition Zone.
Run COCO detection (py_ai_coco_detect)Takes a frame; handles BGR→RGB, mp.Image wrapping, timestamp increment and detect_for_video automatically.
For each target (py_ai_coco_for_each_target)Takes the detection result plus a target dict (e.g. {"person": 0.5}). Skips empty categories, null labels, non-targets and low-confidence results.
Target field (py_ai_coco_target_field)Only valid inside the for-each loop. Reads label, score, x, y, w, h.
Release detector (py_ai_coco_close)Releases resources before the program ends (detector.close()).

Typical flow

# Global Definition Zone
init COCO model "model/efficientdet_lite0.tflite"

# main loop
while True:
    ret, frame = cap.read()
    coco_result = detect(frame)
    for each target in coco_result matching TARGET_OBJECTS:
        draw rect (x, y) to (x+w, y+h)
        draw text "label: score"

Notes

✅ Labels are English (e.g. "cell phone"); dict keys must be English. Map to Chinese with a separate EN→ZH dict for display.
⚠️ Loop variables (_coco_label, ...) have fixed names; do not nest two for-each blocks.
⚠️ The VIDEO-mode timestamp is auto-incremented by the detect block; never modify _coco_timestamp_ms manually.
