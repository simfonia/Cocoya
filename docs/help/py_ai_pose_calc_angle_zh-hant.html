📐 計算三點夾角 (py_ai_pose_calc_angle)

功能說明

依序傳入三個座標點 A、B、C (x, y)，計算中間頂點 B 之夾角。
此積木接受 Tuple (x, y) 座標點，適合直接串接「取得特徵點座標 (get_landmark_xy)」、「取得邊界框中心 (get_bbox_center)」等產出元組的積木。

角度類型 (Type)

類型範圍說明
內角 (Interior)0°–180°預設。標準頂點夾角。
外角 (Exterior)180°–360°360° − 內角。
有符號角 (Signed)−180°~+180°帶方向，正 = 逆時針，負 = 順時針。

方向規則 (± 說明) ⚠️ 重點

以頂點 B 為中心，有符號角之正負 由「由 指向 A 的射線 (BA) 旋轉到 指向 C 的射線 (BC)」決定：

  • 正值 (+) = 逆時針 (CCW) — A 方向旋轉到 C 方向，逆時針為正。
  • 負值 (−) = 順時針 (CW) — A 方向旋轉到 C 方向，順時針為負。
例：A=(0,1)  B=(0,0)  C=(1,0)
  BA 指向「上」，BC 指向「右」
  上→右 為順時針 90°  →  有符號角 = −90°  →  內角 = |−90| = 90°
座標系注意： OpenCV 像素座標 y 軸向下，圖形上顯示的「逆時針／順時針」與數學座標 (y 向上) 相反。
但 數值判斷規則永遠一致：正值 = 由 A 射線逆時針到 C 射線。

推論關係：內角 = |有符號角|，外角 = 360° − 內角。

計算公式

# a, b, c: (x, y) tuples; vertex is b
v1 = (a[0]-b[0], a[1]-b[1])   # ray BA (toward a)
v2 = (c[0]-b[0], c[1]-b[1])   # ray BC (toward c)
dot   = v1.x*v2.x + v1.y*v2.y
cross = v1.x*v2.y - v1.y*v2.x
signed   = degrees(atan2(cross, dot))   # -180..180
interior = abs(signed)                  # 0..180
exterior = 360 - interior               # 180..360

使用範例

# 肘關節角度 (A=肩 11, B=肘 13, C=腕 15)
angle  = cocoya_calc_angle_3pts(shoulder_xy, elbow_xy, wrist_xy)          # 內角
turn   = cocoya_calc_angle_3pts(p1, p2, p3, mode='signed')               # 帶方向
💡 此函式注入為 cocoya_calc_angle_3pts，定義鍵 func_calc_angle_3pts。
不會覆蓋手勢積木既有的 cocoya_get_angle (後者採用 Landmark 物件，定義鍵 func_calc_angle) — 兩者並存。
