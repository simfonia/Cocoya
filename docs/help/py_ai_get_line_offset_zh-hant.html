↔️ 取得循線橫向偏移積木 (py_ai_get_line_offset)

功能說明

取得線的「近端」相對畫面中央的橫向偏移，是循跡控制的比例（P）項。

輸入：推論結果（py_ai_model_predict 的輸出，需為 line_follower 類型）

輸出：數字，範圍 -0.5 ~ 0.5

  • 正值：線在畫面右側（車偏左，需向右修正）
  • 負值：線在畫面左側（車偏右，需向左修正）
  • 0：線置中（車在線中位）

計算方式

近端 = 兩端點中 Y 較大者（畫面上較下方＝離車較近）。

offset = 近端 X - 0.5

數值為 0~1 的比例座標，與畫面解析度無關，換鏡頭或改解析度都不必改程式。

使用範例（差速循跡）

result = predict(frame)
offset = get_line_offset(result) # 橫向誤差（P 項）
angle = get_line_angle(result) # 方向角（D 項）
steer = 100 * offset + 0.5 * angle # 權重請自行調整
motor_left = 50 + steer
motor_right = 50 - steer
💡 建議加上「死區」（例如 |offset| < 0.02 時不修正），可避免車子在直線上來回抖動。
