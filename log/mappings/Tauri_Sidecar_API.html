Tauri Sidecar API 對照表

記錄 Cocoya Tauri 版中 Python Sidecar 通訊的實作方式與 API 使用。

架構概覽

前端 (tauri.js) → invoke('start_sidecar/sidecar_send/stop_sidecar')
  → Rust Command (dataset.rs)
    → stdin/stdout JSON 通訊
      → Python dataset_sidecar.py (CameraService)

Rust 指令

指令參數回傳說明
start_sidecar python_path: String Result<(), String> 啟動 dataset_sidecar.py 進程。維護 stdin/stdout/stderr 的 handle。stderr 輸出透過 sidecar-log event 發送到前端。
sidecar_send command: String, payload: String (JSON) Result (JSON 回應) 發送指令到 sidecar stdin，讀取 stdout 直到找到匹配 requestId 的 response。非 response 行（event）透過 sidecar-event emit 到前端。
stop_sidecar 無 Result<(), String> 關閉 stdin + kill 進程。

Python Sidecar 指令清單 (dataset_sidecar.py)

commandpayload回傳範例說明
listCameras {} {"type":"response","success":true,"cameras":[{"id":0,"name":"Camera 0 (640x480)"}]} 掃描系統中所有可用 webcam。使用 OpenCV cv2.VideoCapture 測試 index 0~9。
startCamera {"deviceId": 0} {"type":"response","success":true} 啟動指定攝影機的 OpenCV 預覽視窗。背景執行緒持續更新 frame。
stopCamera {} {"type":"response","success":true} 停止攝影機，關閉 OpenCV 視窗。
captureImage {"requestId":"xxx","savePath":"...","label":"..."} {"type":"response","success":true,"base64":"...","width":640,"height":480} 擷取目前 frame，回傳 base64 JPEG。若有 savePath 則儲存到磁碟。

Sidecar Event 類型

eventpayload觸發時機
cameraStatus {"type":"event","event":"cameraStatus","running":true/false} 攝影機狀態變化（例如使用者手動關閉 OpenCV 視窗）
注意：sidecar 的 stdout 同時混合 response 和 event。Rust 端會持續讀取 stdout，只有 type=response + 匹配 requestId 的行才會回傳給 caller，其他行（event）透過 Tauri event system emit 到前端。

前端使用方式 (tauri.js)

// 自動檢測 sidecar 狀態並啟動（由 _handleDatasetCommand 處理）
await this._handleDatasetCommand('listCameras', {}, (response) => {
  this._dispatchToFrontend({
    command: 'datasetCameraListResult',
    success: response.success,
    cameras: response.cameras || []
  });
});

關鍵技術細節

  • 逐 byte 讀取 stdout：不使用 BufReader（會內部緩衝吃掉 event），改用 stdout.read(&mut [0u8; 1]) 逐 byte 讀取直到換行。
  • requestId 匹配：每次 sidecar_send 產生唯一 requestId，持續讀 stdout 直到找到 match 的 response。
  • event 轉發：不匹配的 stdout 行透過 window.emit("sidecar-event", line) 送到前端。
  • 前端相容性：_dispatchToFrontend 覆寫加入 window.postMessage，確保 sampler.js 的 window.addEventListener('message') 能正常接收回應。
  • 自動重啟：前端 _handleDatasetCommand 在 sidecar 未啟動時自動呼叫 start_sidecar。
