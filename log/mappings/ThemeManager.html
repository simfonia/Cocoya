1. 架構總覽

theme_manager.js            核心：registry / 模式解析 / cssVars+css 套用 / Msg 覆寫
themes/
├── cocoya_light.js         淺色（Blockly Classic，css 留空）
├── cocoya_dark.js          深色（完全自足：componentStyles + cssVars + css 行為補丁字串）
└── cocoya_candy.js         糖果繽紛（msgColours 積木色示範）

設計原則：一主題一檔；auto 是「模式」不是主題；style.css 不含任何主題規則（僅 FOUC Guard 8 個變數）。

2. Theme Definition 格式

CocoyaTheme.registerTheme({
    id: 'cocoya_candy',              // 唯一 id（localStorage 儲存值）
    labelKey: 'BKY_THEME_CANDY',     // 下拉選單 i18n key
    labelFallback: 'Candy Pop',
    isDark: false,                   // 深色行為（icon 反轉/grid 隱藏由 class 涵蓋）與 auto 解析
    hideGrid: false,
    blockly: {                       // Blockly Theme（componentStyles 即時生效）
        name: 'cocoya_candy', componentStyles: { ... }
    },
    msgColours: { LOGIC:'#8E7CF8', ... },  // 覆寫 Blockly.Msg['COLOUR_'+key]（選配）
    cssVars: { '--toolbar-bg': '#...', ... },  // UI 調色盤（body inline style）
    css: `.some-selector { ... }`          // 主題專屬規則（注入 <style id=cocoya-theme-css>，選配）
});

3. API 對照

方法說明
registerTheme(def)註冊主題（themes/*.js 於載入時呼叫）
getThemes()回傳 [{id,labelKey,labelFallback,isDark}]，首頁下拉由此生成
getMode()'auto' 或主題 id；舊值 light/dark 自動遷移為 cocoya_light/dark
setMode(mode)存 localStorage['cocoya_theme_mode'] → CocoyaBridge.send('reloadWebview')（fallback location.reload()）＋800ms 保險絲
applyMsgColours()語系載入後、積木註冊前覆寫 COLOUR_*（lifecycle.initializeCocoya 呼叫）；僅覆寫有定義的鍵
apply(force)body class + cssVars(inline) + _applyThemeCss + workspace.setTheme + grid/minimap
startWatching()MutationObserver(body.vscode-*) + matchMedia → auto 即時跟隨系統

4. reloadWebview 跨平台重載鏈

前端 setMode() ──send('reloadWebview')──▶ Host
  VSIX: cocoyaManager.ts case reloadWebview
        → webview.html = getWebviewContent(...) + '<!-- cocoya-rebuild: Date.now() -->'
        （★ 相同 HTML 字串賦值不會重載，時間戳強制刷新）
  Tauri: bridge/tauri.js case reloadWebview → location.reload()
保險絲：送出後掛 800ms 計時器，host 未重建則 fallback location.reload()
注意：改動 src/*.ts 後必須 npm run compile（out/ 才會更新）
