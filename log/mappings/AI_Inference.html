2. 推論結果契約（predict() 回傳字典）

任務回傳結構解析積木
classifier{type, label, confidence}py_ai_get_label / py_ai_get_confidence
detector{type, objects: [{label, confidence, bbox: (x1,y1,x2,y2)}]}py_ai_get_bbox / py_ai_get_bbox_center
line_follower{type, line: (x1,y1,x2,y2), offset, angle, direction, confidence}py_ai_get_line / py_ai_get_line_end / py_ai_get_line_offset / py_ai_get_line_angle / py_ai_get_direction
table{type, prediction, confidence}（尚未實作）—

line_follower 欄位語意：

  • line：模型回歸的兩端點（歸一化 0~1，與 Dataset Manager 的線段標註同座標系）。
  • offset：近端 X − 0.5；範圍 −0.5~0.5，正值＝線在畫面右側。近端＝兩端點中 Y 較大者（畫面較下方）。
  • angle：atan2(遠端X−近端X, 近端Y−遠端Y) 換算為度；0 = 正前方，正值 = 順時針（與 HuskyLens 角度語意一致）。
  • direction：由 offset 推得（|offset| ≤ 0.05 視為置中），值為 left / right / forward / none。無影像時整組回 0 且 direction="none"。
  • confidence：回歸模型無校正後信心值 → 固定 1.0（與 detector 同策略）。
int8 模型輸出還原：int8（uint8 in/out）模型的輸出張量是 0~255，必須 /255.0 還原成 0~1。此還原在 _classify、_detect、_follow_line 三處**都必須**存在；_detect 先前缺漏（2026-09-19 修正），缺失會讓 bbox 值放大 255 倍而難以察覺。辨識方式：self.isf（輸入 dtype 是否 float32）。

3. 兩個「循線」世界（重要觀念區分）

世界 A：HuskyLens 內建循跡世界 B：Cocoya 自訓循線模型
需要訓練否（機上自學習／內建演算法）是（DM 標註 → py_ai_train_run → .tflite）

兩者的角度語意刻意對齊（0 = 正前方、順時針為正），因此**同一套循跡控制器可以互換資料來源**（PC 端模型輸出 or HuskyLens 回報），教學上可從「開箱即用」無痛過渡到「自己訓練」。

4. 循線控制實務（P + D 控制器）

有效的循跡控制器＝橫向誤差（P 項） + 線的方向（D／預測項）：

offset = get_line_offset(result)     # 近端相對畫面中央：車在線的哪一側
angle  = get_line_angle(result)      # 線往哪個角度延伸：提前知道要彎了
steer  = Kp * offset + Kd * angle    # Kp、Kd 需實機調
motor_left  = base + steer
motor_right = base - steer
  • 只有 P 項：直線很穩，但進彎反應慢、容易衝出線外。
  • 只有角度：等於瞄準遠端點（pure pursuit），急彎會切內側抄近路。
  • P + D：兩者互補，這正是「不切西瓜、乖乖沿線」的關鍵。

實作要點：

  • 死區：|offset| < 0.02 不修正，避免直線抖動。
  • 限幅與斜率限制：steer 夾在合理範圍，且限制每秒變化量。
  • 掉線處理：direction == 'none' 時沿用最後一次 steer 並降速（不要用 0 硬轉）。
  • 增益起始值：Kp 先小（如 100）、Kd 約 Kp 的 1/100 量級再實調（單位：offset 為 ±0.5、angle 為 ±90 度）。
  • 方向符號：馬達左右方向取決於車體接線，務必先以「車置中、線偏左」情境驗證符號再調增益。
標註與訓練的一致性：模型輸出座標與標註同系（比例座標），因此資料集應固定同一顆鏡頭與安裝角度；若換鏡頭/位移，需重新採集或至少重標一批驗證。線段標註「兩點」不可改為單點——單點會失去方向（D 項）資訊，且與現行 Dense(4) 回歸頭不符。

5. 已知限制

  • py_ai_train_run 的巢狀欄位（驗證比／擴增／Dropout／LR／Epochs／Batch／Backbone／DNN 層／優化器／輸出格式）在 VSIX 與 Tauri 雙模下皆走同一產生器；修改時需同步 resources/train_templates/ 的 argparse 介面。
  • table 任務（表格資料）推論尚未實作，回傳固定值。
  • 解析積木在找不到欄位時一律回安全預設（0 / 0.0 / 'none' / (0,0,0,0)），不拋錯；教學時建議先以「取得信心度 > 0」判斷是否真的有結果。
