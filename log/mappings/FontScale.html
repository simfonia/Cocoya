2. 三條鐵則

1) 元件 CSS 一律 calc(Npx * var(--fs-x)) —— 不得再出現裸 px 字級（T 範圍尚未納入者除外）。
2) 放大字級若造成裁切/溢出，正解是「把該容器 height/min-height/padding/line-height 綁同一個變數」，不是把字級調回去。
3) --dsm-font-scale 是下游唯讀變數（dataset_manager.css）：要改字級請改上游 --fs-p1/p2/p3。

3. DM：變數重綁定映射（43 處 font-size 皆已 calc 化）

.dataset-manager-overlay                               { --dsm-font-scale: var(--fs-p2, 1); }
.dataset-manager-overlay.dataset-entry-phase           { --dsm-font-scale: var(--fs-p1, 1); }
.dataset-manager-overlay.dataset-annotation-fullscreen { --dsm-font-scale: var(--fs-p3, 1); }

前置條件（2026-09-16 追加查證）：DM 的 43 處 font-size 必須是 calc(Npx * var(--dsm-font-scale))，映射才會生效——昨日的 calc 版曾在當日被退回成裸 px，本日已補回（見 log/work/2026-09-16.md 追加修正）。

5. 容器也要跟著字級成長（實例：toolbar 下拉選單）

字級放大後若「文字換行／被裁切」，先查該文字所在容器是否為固定寬高（min-width/width/height/line-height）。正解是讓容器跟著內容成長，不是把字級調回去。
