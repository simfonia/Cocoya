### BBox 標註 UI 重構（全寬 3 欄布局）

#### 需求
依 `log/plan/BboxAnnotationUIImprovement.md` 改善 Dataset Manager 縮圖點入 bbox 標註 UI 的兩項缺點：
1. 顯示在右方預覽面板版面太小（固定高度 380px）
2. 每標註一張圖就需點「返回列表」再點下一張縮圖，效率低

#### 設計決策
- **CSS class-based 布局切換**：為 `.dataset-manager-body` 添加 `.dataset-annotation-mode` class，隱藏 source/schema 面板，preview panel 成為單欄全寬

- **單一 debounce timer**：`state.annotationMode.saveTimer` 用於防抖自動儲存
- **鍵盤事件綁定在 canvas element**（需 `tabindex=0`），退出時統一清理
- **向後兼容**：`exitAnnotationMode()` 在非標註模式下也需安全呼叫

## 技術深挖 (Technical Deep Dive)

### 布局切換機制
- 進入標註模式：`.dataset-manager-body` 加 `.dataset-annotation-mode` class，透過 CSS 覆寫 `grid-template-columns: 1fr`，並隱藏 source/schema 面板
- 退出：移除 class + source/schema 面板 `style.display = ''` 恢復
- 優點：不直接操作 inline grid-template-columns，維護性佳

### 鍵盤事件生命週期
- 鍵盤事件綁定在 canvas element（`tabindex=0`），畫布自動聚焦
- 當使用者點擊右側控制欄按鈕/輸入框時，畫布失去焦點，快捷鍵暫時失效
- 點擊畫布空白處時（mousedown handler）清除選中並重新聚焦
- 事件 handler 存放在 `UICanvas.state.handlers.keydown`，`exitAnnotationMode()` 透過 `unbindEvents()` 統一清理

### 自動儲存防抖
- `onUpdate` 回調使用單一 `state.annotationMode.saveTimer` debounce timer（300ms）
- `navigateToImage()` 切換圖片前先呼叫 `saveCurrentAnnotations()` 強制立即儲存
- `closeDatasetManager()` 清理 timer 避免 DOM 銷毀後 callback 執行

### 縮圖勾號狀態
- 已標註 = `img.annotations && img.annotations.length > 0`
- `updateThumbnailHighlight()` 在切換圖片時重新計算 current/annotated class
- `removeAnnotation()` 刪除後同步更新縮圖與進度
