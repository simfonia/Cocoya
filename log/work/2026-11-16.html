技術深挖 (Technical Deep Dive)

1. 序列埠「自動暫停寫入、上傳後自動續傳」的架構缺點評估

通訊語意錯亂（MCU重啟後灌入舊協議指令）、即時串流嚴重延遲、雙向交握狀態機失步與假死感。

2. 為何不能單純由 Serial Hub 端主動撤銷 B 的寫入？

Hub 僅為 TCP 連線層，無法跨進程 kill OS 級 Python 行程；Webcam 會殘留占用，B 視窗 UI 亦無法復原。
