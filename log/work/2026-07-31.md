### Dataset Manager VSIX 版語系修復

#### 問題
- VSIX 版 Dataset Manager 在啟動時仍可能先套用 fallback 的中文文字，導致英文環境下 UI 內容不符合預期。

#### 根本原因
- Dataset Manager 模組有自己的 i18n 載入流程，且在 webview 初始化語系時機上與主應用不同步。
- 模組在初始載入時先讀取自身語系檔，之後主應用才完成最終語系設定，導致其畫面仍維持舊語系。

#### 修復
- 在主應用初始化完成後，額外觸發 Dataset Manager 的 i18n refresh。
- Dataset Manager 會在收到最終 locale 後重新載入對應語系檔，並重建/重繪 Modal 內容。
- 相關檔案：
  - `ui/src/app/lifecycle.js`
  - `ui/src/modules/dataset_manager/index.js`
  - `ui/src/modules/dataset_manager/ui_layout.js`

#### 驗證
- `npm run compile`：成功
- `npm run build`：成功
