## 追加：release 模板 import common 失敗（\\?\ 前綴）修復（2026-09-02 第二輪）
- **症狀**：`ModuleNotFoundError: No module named 'common'`，traceback 路徑帶 `\\?\`。
- **根因**：Rust `BaseDirectory::Resource::resolve()` 回傳 canonicalized `\\?\` 路徑（同 2026-08-31 sidecar WinError 123 坑）。模板 `sys.path.insert(0, dirname(__file__) + '/..')` 未正規化，`\\?\` 模式下 `..` 不被解析 → common 找不到。
- **修復（雙保險）**：
  1. `utils.rs::get_train_templates_path()` 新增 normalize()：回傳前剝除 `\\?\` 前綴（COCOYA_TRAIN_TEMPLATES env 於源頭乾淨）。
  2. classifier/detector_train.py：`_script_dir = abspath(dirname(__file__))` → startswith('\\\\?\\') 時剝 4 字元 → normpath(join(dir,'..')) 再 sys.path.insert。
- **驗證**：py_compile PASS、cargo check PASS；以 AST 抽取模板實際常數確認值為 `\\?\`（repr 4bs+?+2bs）；以 chr(92) 構造 `\\?\C:\\x\\y.py` 實測 abspath 保留前綴、剝除+normpath 得乾淨根。temp_scripts 測試檔已刪。
- **教訓（蒸餾候選）**：Rust → Python 跨界路徑一律先剝 `\\?\`；PowerShell 測試含反斜線字面量不可靠，改 chr(92)/寫檔驗證。

## 追加：遠端訓練跳出 python cmd 黑視窗修復（2026-09-02 第七輪）
- **症狀**：release 執行遠端訓練（連上 ssh）時彈出執行 python 的 cmd 黑視窗，且執行完不關閉。
- **根因**：Tauri 為 GUI subsystem（無 console），但 `dataset.rs::start_sidecar` 與匯出處啟動 dataset sidecar 的 `Command::new(python)` **未設 CREATE_NO_WINDOW** → Windows 為本機長駐 sidecar（讀 stdin 迴圈）開 console 黑窗，且不會自動關閉。sidecar 內 trainLocal Popen 亦缺旗標（次要）。

  2. sidecar.py：頂層定義 `_POPEN`（os.name=='nt' → creationflags=0x08000000），套用於 paramiko pip 安裝 check_call 與 trainLocal 子進程 Popen。
- **驗證**：cargo check PASS、py_compile PASS。待實機：release 遠端訓練不再彈黑窗。

## 追加：VSIX 本地訓練 cp950 UnicodeDecodeError 修復（2026-09-02 第十輪）
- **症狀**：VSIX 執行本地訓練，cocoya_run.py line 78 for line in process.stdout 拋 cp950 codec can't decode。
- **根因**：產生器 ai_inference_generators.js 產出的 train_model() 內 Popen(..., text=True, universal_newlines=True) 未指定編碼，Python 用 locale(cp950) 解碼子進程 classifier_train.py 的 UTF-8 輸出 → UnicodeDecodeError。

- **驗證**：node --check PASS、vite build PASS。
