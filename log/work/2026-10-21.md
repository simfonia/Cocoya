### 1.5 踩坑紀錄（重要）

- **`datasetBridge` 是 module singleton，內部 dispatcher 會綁定「首次使用時的」`window.CocoyaBridge` 參照。**
  測試換 fake bridge 前必須先 `datasetBridge.dispose()`，否則訊息會送到舊 fake 而永久 timeout。
  目前 `resetSampler()` 同時呼叫 `Sampler.dispose()` ＋ `datasetBridge.dispose()`。
- **Node mock timers 只啟用 `setInterval`**（`t.mock.timers.enable({ apis: ['setInterval'] })`），
  以避開 `clearInterval` mock API 相容問題。
- **`takeSnapshot()` 回應必須帶回對應的 `requestId`**，否則 pending request 會 timeout。
- **變數遮蔽是隱形 bug**：`newUrl` 若與 `this.state.lastPreviewUrl` 混淆，catch 分支會 revoke 錯的 URL。
  守門靠「`newUrl` 改成 `const` 區域變數」的 mutation 驗證（見 §1.6）。
- **`sampler.test.mjs` 重建方式**：務必**分段**用 editor 工具建立（`insert_line` 逐段追加），
  不可重複以固定行號插入，也不可用 PowerShell `Set-Content` 改寫原始碼（會打亂行尾／內容）。

## 1.9 Pyright 診斷清零（2026-10-21 追加）

### 1.9.1 問題

Pylance / Pyright 在 `resources/dataset_manager/**` 與 `tests/e2e/**` 產生大量紅字
（`reportMissingImports` 為主：dataset_manager 內部彼此以平鋪 import 互相引用，
如 `from remote_ssh import ...`，靜態分析器無法解析）。

### 1.9.2 修法

| 項目 | 修法 |
|---|---|
| 匯入解析 | `pyrightconfig.json` 的 `extraPaths` 與 `include` 加入 `resources/dataset_manager`（該目錄內部為**平鋪 import，非套件**，故指向目錄本身而非其父層） |
| `camera_service.py` | `base64.b64encode(buffer)` → `buffer.tobytes()`（numpy 陣列不保證支援 buffer protocol） |
| `media_pipe_service.py` | `mp.solutions` 為動態命名空間 → `cast(Any, mp).solutions` |
| `local_training.py` / `remote_tflite.py` | `process.stdout` / `p_conv.stdout` 型別為 `IO[str] \| None` → 先取局部參照並 `assert ... is not None` |
| `remote_tflite.py` | `import importlib` → `import importlib.util`（使用 `importlib.util.find_spec`，原 import 無法解析該屬性） |
| `remote_ssh.py` | docstring 內 `\\?\` 逸出序列 → 改用 raw string `r"""`（消除 `reportInvalidStringEscapeSequence` 警告） |
| `line_dataset.py` | `random.shuffle(ndarray)` 型別不符 → 先轉 Python list 洗牌再轉回 ndarray |
| `test_detector_curves.py` | `spec` 可能為 None → `assert spec is not None` / `assert spec.loader is not None`；`captured` 標為 `Dict[str, Any]` |
