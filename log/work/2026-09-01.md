## Stage 5 收尾切片：locale refresh race 修復（§8.2 步驟 5）

### 審查範圍

- `index.js`：`getPreferredLocale` / `getLocaleCandidates` / `loadI18n` / `refreshLocale` 鏈路
- `ui_layout.js:1467` `refreshI18n()`：modal 重建 + 應重開語意
- `lifecycle.js:162`：語系切換 → `window.CocoyaDataset.refreshI18n()`

### 發現與修正

- **T5-2 race（`index.js` loadI18n）**：舊實作以 `document.querySelector(script[src=...])` 判斷已載入；同一 URL 的 script 仍在載入中時第二次呼叫會**立即 resolve**，`refreshI18n()` 在新語系鍵值就緒前重建 UI → 顯示舊語系。
- 修正：改為 `localeScriptPromises` Map 記錄每個 URL 的 in-flight promise（onload 才 resolve、onerror 清除記錄並 fallback 下一候選），行為契約不變（最終 resolve、回退鏈 zh/en 不變）。
- `refreshI18n()` 本體審查：modal 重建走 `initDatasetManagerUI()`，Bridge listener 訂閱洩漏已於 Stage 4 切片 2 修復（offBridgeMessage 掛 modal 並於卸載前解除）；`state.isOpen`/重開語意正確，無需修改。
