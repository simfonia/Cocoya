## 技術深挖 (Technical Deep Dive)

### 1. 物件偵測架構升級路徑聚焦：為何優先實作 Keras Spatial Head？

在 2026-11-19 的架構討論中，針對物件偵測從舊版 Legacy GAP + Dense(4) 單框回歸遷移至現代架構的策略進行了收斂：
1. **50 分鐘課堂可行性**：
   - 舊版 Legacy 單框回歸因全域池化（GAP）抹除空間特徵，導致 IoU 只有 0.07~0.08，無法追蹤。
   - Keras Spatial Head（雙尺度空間特徵融合 + Stride-8 Heatmap/Size map）POC 在 CPU 訓練僅需約 2.8 分鐘（168 秒），mean IoU 達 0.6556，直接導出 Float32 TFLite（5MB），非常適合 50 分鐘即席教學。
   - YOLOv8n POC 在 CPU 訓練耗時 38.8 分鐘，若在課堂即席訓練會大幅超時，適合課後專題或進階學生。
2. **依賴環境純淨性與授權防護**：
   - Spatial Head 完全建立在既有的 TensorFlow/Keras/TFLite 基礎上，零額外 Python 套件負擔。
   - YOLO 涉及 Ultralytics AGPL-3.0 授權、預訓練權重散布限制與龐大的 PyTorch CPU 套件。優先實作 Spatial Head 能徹底繞過這些外部風險。

### 2. Blockly 積木介面策略：方案 B（另立進階積木）

關於使用者是否應在 `py_ai_train_run` 中透過新增 `MODEL_ARCH` 欄位來選擇雙架構：
- **決策**：現階段 `py_ai_train_run` **不新增欄位**。
- **原因**：
  - 舊 Legacy 架構確定廢棄（不相容），現有的「物件偵測（`object_detection`）」選項底層直接全面切換為優良的 Spatial Head，使用者無感升級，介面最簡潔。
  - YOLO 的超參數（imgsz、yolov8n.pt 權重、專屬 augmentation）與 Keras 傳統骨幹（Backbone、DNN Layers、優化器、TFLite 量化輸出）截然不同。若硬塞進同一積木，會產生大量相互衝突或無效的欄位，增加初學者的困惑。
  - 後續若引進 YOLO，確定採**「方案 B：另立專用進階多物件訓練積木」**，讓入門與進階各自擁有獨立且清晰的積木體驗。

### 3. Spatial Head 標籤生成與負樣本機制 (S1)

1. **2D 高斯熱圖 (Heatmap) 與尺寸圖 (Size Map)**：
   - 骨幹輸入尺寸為 $224 \times 224$，在 Stride-8 特徵層上其解析度為 $28 \times 28$。
   - 熱圖峰值落在目標中心網格 $(grid_x, grid_y)$，以 $\sigma = 1.5$ 產生 2D 高斯分佈，中心峰值為 1.0。
   - 尺寸圖大小為 $(28, 28, 3)$：在熱圖響應 $\ge 0.3$ 的目標鄰域填入 $[w, h]$，並將第 3 通道設為 $1.0$ 作為有效遮罩 (mask)；其餘非目標區域全為 $0.0$。
2. **負樣本（無目標背景）與未分類框過濾**：
   - **負樣本保留**：當影像無任何標註框時，作為真實負樣本保留。產生全零熱圖與全零尺寸圖（mask=0）。在訓練時，Focal Heatmap Loss 會懲罰所有非零假警報，而 Masked Size Loss 則因 mask=0 不計算尺寸誤差，有效抑制空場景下的假框誤報。
   - **未分類框略過**：當影像內僅包含未分類框（`class_id < 0`）時，輸出警告並略過，防止將有物件但尚未分類的資料誤當負樣本污染訓練。
   - **多框明確拒絕**：若單影像內有 $> 1$ 個有效標註框，主動拋出明確的 `ValueError`，明確提示使用者目前單目標架構之邊界。
3. **特徵圖維度的隨機水平翻轉**：
   - 由於熱圖 $(28, 28, 1)$ 與尺寸圖 $(28, 28, 3)$ 本身即為 2D 空間分佈矩陣，水平翻轉特徵圖會自然鏡射目標的中心橫座標 $x$（$27 - x$），且目標的尺寸 $[w, h]$ 在水平鏡像下保持不變。
   - 實作在批次維度下利用廣播 `tf.where` 與 `tf.image.flip_left_right` 實現同步翻轉，確保資料擴增下的空間一致性。

### 4. Spatial Head 模型架構、雙輸出損失與空間解碼評估 (S2)

1. **雙尺度空間特徵融合網路 (Two-Scale Spatial Feature Fusion)**：
   - 傳統 Legacy 架構使用 GlobalAveragePooling2D 壓平成 1D 向量後接 Dense(4)，徹底抹煞了特徵的空間座標分佈，造成回歸向均值嚴重塌陷。
   - Spatial Head 捨棄 GAP，從骨幹網路（如 MobileNetV2）分別提取：
     - **Stride-8 特徵層**（`block_6_expand_relu`，尺寸 $28 \times 28 \times 192$）
     - **Stride-16 特徵層**（`block_13_expand_relu`，尺寸 $14 \times 14 \times 576$）
   - 將 Stride-16 特徵經由 `UpSampling2D(size=(2, 2), interpolation='bilinear')` 雙線性插值放大至 $28 \times 28$，與 Stride-8 特徵透過 `Concatenate` 沿通道維度融合（共 768 通道）。
   - 提煉頭部（Refinement Head）：`Conv2D(96, 3, padding='same', activation='relu')` $\to$ `Dropout(dropout_rate)` $\to$ `Conv2D(64, 3, padding='same', activation='relu')`。
   - 雙輸出頭：
     - `heatmap`: `Conv2D(1, 1, activation='sigmoid', bias_initializer=Constant(-2.19))`，輸出 $(28, 28, 1)$。$-2.19$ 偏置對應 $\sigma(-2.19) \approx 0.1$，在訓練初期即壓制背景躁動。
     - `size_map`: `Conv2D(2, 1, activation='sigmoid', bias_initializer=Constant([-2.2, -1.9]))`，輸出 $(28, 28, 2)$，對應目標正規化寬高。

2. **自訂雙損失函數設計**：
   - **Modified Focal Heatmap Loss**：
     $$L_{hm} = -\frac{1}{\max(N, 1)} \sum_{xy} \begin{cases}
     (1 - \hat{Y}_{xy})^\alpha \log(\hat{Y}_{xy}) & \text{if } Y_{xy} = 1 \\
     (1 - Y_{xy})^\beta (\hat{Y}_{xy})^\alpha \log(1 - \hat{Y}_{xy}) & \text{otherwise}
     \end{cases}$$
     其中 $\alpha = 2, \beta = 4$。對 784 個點中的 783 個非中心點實施難易樣本非對稱處罰，在背景負樣本上自動降權高斯鄰域、重罰假陽性。
   - **Masked L1 Size Loss**：
     $$L_{size} = \frac{1}{\max(N, 1)} \sum_{xy \in \text{pos}} |S_{xy} - \hat{S}_{xy}|$$
     僅在目標中心點（$Y_{xy} = 1$ 且尺寸 $> 0$）計算 L1 損失；全負樣本與背景區域遮罩為 0，完全不參與尺寸梯度更新。
   - **損失權重平衡**：`loss_weights={'heatmap': 1.0, 'size_map': 5.0}`，有效平衡數值尺度。

3. **空間解碼與評估指標**：
   - 實作 `evaluate_spatial_detector(model, dataset, conf_threshold=0.3)`：
     - 預測熱圖峰值處解碼中心點座標 $(cx, cy) = ((grid_x + 0.5) / 28.0, (grid_y + 0.5) / 28.0)$，取對應網格尺寸 $(w, h) = \hat{S}_{xy}$。
     - 輸出三個核心指標：正樣本平均 IoU (`mean_iou`)、IoU@0.5 達成率 (`iou50_rate`)、負樣本誤報率 (`fp_rate`)。
   - 報告與歷史儲存對齊：`finalIoU` 保留舊版欄位名供前端無縫相容，並擴充 `finalIoU50` 與 `finalFPRate`。
   - 預設產出 Float32 TFLite（~5.0MB），確保課堂學生電腦快速即時推論。

### 5. Spatial Head 即時推論解碼器與空場景過濾 (S3)

1. **張量自動識別**：
   - 在 `_ModelInference.__init__` 中，根據張量形狀動態解析輸出索引：
     - 若 `shp == [1, 28, 28, 1]` 則識別為 `hm_idx` (Heatmap)。
     - 若 `shp == [1, 28, 28, 2]` 則識別為 `sz_idx` (Size map)。
   - 使用 `getattr(self, "hm_idx", None)` 進行防禦性存取，確保即便在測試 stub 未完整執行 `__init__` 的情境下也能安全 fallback。

2. **空間峰值解碼與邊界還原**：
   - 提取熱圖第一通道，透過 `np.argmax(hm[..., 0])` 結合 `np.unravel_index(..., (28, 28))` 鎖定最高響應網格座標 $(grid_y, grid_x)$。
   - 峰值置信度：$conf = hm[grid_y, grid_x, 0]$。
   - **空場景抑制 (Empty Scene Suppression)**：
     - 若 $conf < 0.3$，判定為環境背景或無目標，回傳空目標列表 `{"type": "object_detection", "objects": [], "confidence": conf}`。徹底杜絕舊版 Legacy GAP 任何情況下皆強行回傳全域中心虛假框的致命缺陷。
   - 目標中心座標與寬高計算：
     - $cx = (grid_x + 0.5) / 28.0$，$cy = (grid_y + 0.5) / 28.0$
     - $w = sz[grid_y, grid_x, 0]$，$h = sz[grid_y, grid_x, 1]$
     - 邊界框限制於 $[0, 1]$ 範圍：
       $$x_1 = \text{clip}(cx - w/2), \quad y_1 = \text{clip}(cy - h/2), \quad x_2 = \text{clip}(cx + w/2), \quad y_2 = \text{clip}(cy + h/2)$$
   - 回傳標準物件格式：`{"type": "object_detection", "objects": [{"label": label, "confidence": conf, "bbox": (x1, y1, x2, y2)}], "confidence": conf}`。

3. **Blockly 產生器無縫相容**：
   - 積木 `py_ai_get_bbox` 依舊透過 `.get("objects", [{}])[0].get("bbox", ...)` 取值；當空場景時平穩退回 `(0, 0, 0, 0)`。
   - 積木 `py_ai_get_confidence` 既可透過最外層 `"confidence"` 取得整體場景峰值，亦可由 `objects[0]["confidence"]` 取得目標信心度。
   - `spatial_detector_inference.test.mjs` 契約測試全綠，且全量 603 項 UI 測試零回歸。

### 7. 離線預訓練權重備援與無網路防呆提示機制

為徹底避免使用者在無外部網路環境（如封閉課堂、競賽場地）首次訓練時，因無法自 Google 伺服器下載 ImageNet 權重而自動降級為「隨機初始化權重 ＋ Backbone 凍結 (`fine_tune=False`)」引發的空間特徵均值塌陷：
1. **本地備援權重落地**：
   - 下載 MobileNetV2 ImageNet 預訓練權重檔（無頂部分類層，約 9.4MB）存放在 `models/ImageNet/mobilenet_v2_weights_tf_dim_ordering_tf_kernels_1.0_224_no_top.h5`。
2. **自動備援退回邏輯**：
   - 在 `detector_model.py` 中實作 `find_local_backup_weights(key)`，當 `weights='imagenet'` 在線上下載觸發例外時，優先向上尋找 `models/ImageNet/` 本地目錄。
   - 若本地存在對應權重，則自動退回引用本地權重進行初始化，確保即便在完全斷網的環境下也能保有 ImageNet 空間語意萃取能力。
3. **雙語系防呆警告提示 (i18n)**：
   - 若連本地備援權重亦不存在、必須降級為 `weights=None`（隨機初始化），且使用者目前設定 `fine_tune=False`（骨幹被凍結）：
   - 自動檢測 `os.environ.get('COCOYA_LANG')` 或預設值，在終端機輸出雙語系（中文／英文）明顯框線警告：
     ```text
     ======================================================================
     ⚠️ 注意: 目前使用隨機初始權重且微調為關閉 (fine_tune=False)！
       無預訓練權重的骨幹若被凍結，特徵層輸出隨機雜訊，物件偵測空間定位將無法收斂。
       建議方案: 開啟微調 (fine_tune=True) 讓骨幹參與學習，或將權重檔放至 models/ImageNet/
     ======================================================================
     ```
   - 讓學生或教師能第一時間獲知診斷原因與解決方案，不再陷入黑箱均值盲點。
