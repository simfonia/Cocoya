# Cocoya 開發日誌 — 2026-08-20

## 任務：Tauri 多視窗 terminal/serial 污染與視窗間 serial 交接

### 需求
1. Tauri 開啟多視窗時，終端機畫面彼此共用（互相污染）。
2. 外接 MCU 下多視窗切換時，期望「失焦視窗自動釋放 Serial port、作用視窗自動取得」。

### 問題 1 根因：`emit` 為全域廣播，非視窗單播
- 後端 `python.rs`/`mcu.rs` 所有終端/訓練事件皆用 `window_clone.emit("python-log"|"python-error"|"training-*", ...)`。
- 依本專案既有踩坑紀錄（AGENTS.md 多視窗完整性規範、log/details_backup_20260509、log/work/2026-06-25）：**Tauri 的 `emit` 是全域廣播**，會送達每個視窗的 listener；`closeRequested` 早已改用 `emit_to` 修正，唯 terminal 事件漏改。
- 前端 `tauri.js:654 _setupTauriListeners()` 已用 `appWindow.listen()`（視窗限定訂閱），故只需後端改 `.emit_to(&own_label, ...)` 即可隔離。

### 問題 2 現況：無焦點交接機制
- 序列埠狀態本就按 `window.label()` 隔離（`python_processes[label]`），但切換視窗不會自動釋放/取得；兩窗同時開同一 COM 埠會衝突。

### 修改清單（階段一：多視窗終端機隔離）
- `src-tauri/src/commands/python.rs`
  - `run_python`：banner + stdout/stderr 三處 `.emit` → `.emit_to(&own_label, ...)`；因 `move` 閉包 String 非 Copy，每執行緒建立 `run_stdout_label`/`run_stderr_label` = `own_label.clone()`。
  - `start_training`：DGX 分支與 training-log/complete/error 四處 → `.emit_to(&own_label, ...)`，執行緒用 `train_stdout_label`/`train_stderr_label` clone。
  - `stop_python`：kill `python_processes[label]` 後一併呼叫 `crate::commands::mcu::stop_serial_monitor(state, label)`。
- `src-tauri/src/commands/mcu.rs`
  - `deploy_mcu`、`open_serial_monitor`、`erase_filesystem`、`reset_firmware(esptool)` 之 `python-log`/`python-error` 全部 `.emit_to`。
  - 各執行緒以 `xxx_label = own_label.clone()` 避免 double move。

### 修改清單（階段二：方案 B 視窗焦點交接）
- `src-tauri/src/state.rs`：新增 `SerialMonitorSession { port, python_path, lang, child }`、`SerialMonitorWant { port, python_path, lang }`；`AppState` 新增 `serial_monitors`、`serial_wants` 兩張 HashMap（皆以 window label 為 key）。
- `src-tauri/src/commands/mcu.rs`
  - 抽出 `spawn_serial_monitor()`（open_serial_monitor 與聚焦重取共用）：發現同埠被其他視窗佔用即先 `stop_serial_monitor`；新增 spawn 於 `serial_monitors.insert` + 記 `serial_wants`；輸出用 `.emit_to`。
  - `open_serial_monitor()`：`stop_python` + `spawn_serial_monitor`。
  - 新增 `stop_serial_monitor(state,label)`：kill `session.child` 並從 `serial_monitors` 移除（保留 `serial_wants`）。
  - 新增 `#[tauri::command] set_window_focus(focused: bool)`：`focused=true` 若有 `serial_wants[label]` 且無啟用 session → 延遲 400ms 後 `spawn_serial_monitor` 重取；`focused=false` → `stop_serial_monitor` 釋放（保留 wants）。
- `src-tauri/src/lib.rs`：`AppState` 初始化兩新欄位；invoke_handler 註冊 `set_window_focus`；on_window_event 關閉時清理 `serial_monitors`/`serial_wants`。
- `ui/src/bridge/tauri.js` `_setupTauriListeners`：`document.addEventListener('blur'/'focus')` → `this.tauriInvoke('set_window_focus', { focused: bool })`（fire-and-forget）。
- `src-tauri/permissions/commands.toml`：`allow` 加入 `set_window_focus`。
- `docs/backend_api_manifest.md`：MCU Commands 表 + Command Signatures 表新增 `set_window_focus { focused }`。
- `AGENTS.md`：多視窗完整性規範補「emit_to 鐵則」用法、已轉換清單、方案 B 序列埠交接說明。
