## 技術深挖 (Technical Deep Dive)

### Python 區域 import 遮蔽全域 import 的作用域陷阱

在 Python 中，`import X` 本質上是「把模組 X 綁定到目前函式的區域命名空間」的賦值。只要一個函式**任何位置**出現 `import X` 或 `X = ...`，Python 就會把整個函式內所有 `X` 都視為**區域變數**（local），即使函式頂層早就有全域 `import X`，也不會自動 fallback 到全域。

因此：
```python
import json          # 全域

def run():
    # 這裡的 json 已被下方 import json 判定為區域變數
    obj = json.loads(line)      # ← 在 import json 之前執行 → UnboundLocalError!
    if cmd == "export":
        import json             # 使整個 run() 的 json 變成 local
        ...
```

**教訓**：
1. 不要在較大的方法/函式內「重複 import」頂層已 import 的模組——會意外把同名名字降級為區域變數，影響整個函式。
2. 若區域 import 是為了條件式載入，改用 `importlib.import_module(...)` 或模組級 `try/except import`（頂層），避免污染函式作用域。
3. 主迴圈（stdin 指令解析）必須保持自頂層直接可得 `json`/`os`，否則任何指令都會在解析層失敗。
