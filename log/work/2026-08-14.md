## 技術深挖 (Technical Deep Dive)

### Tauri 指令引數 camelCase→snake_case 自動對映
前端 `tauriInvoke('dataset_save_progress', { folderPath, projectName, specJson })` 對應 Rust `dataset_save_progress(folder_path, project_name, spec_json)`。Tauri 2.0 指令引數預設自動將 JS camelCase key 對映至 Rust snake_case 參數，無需額外 `rename`。本指令為純「收參數→寫檔→回傳字串」，不使用 `Window`/`State`（避免鎖與序列化額外複雜度）。

### 專案根 SSOT 的儲存路徑決策
- VSIX：`handleDatasetSaveProgress` 以 `manager.currentFilePath` 的 dirname 為根（同 M4a 修正後落盤基準）。
- Tauri：由前端 `tauri.js` 在 Bridge 層解析根（`_anchor` 快照 + 必要時重新 `get_project_anchor`），並把 `projectRoot` 作為 `folder_path` 傳給指令 → 後端保持「純檔案操作」，決策集中在前端 SSOT。未錨定回傳錯誤，與 VSIX 防呆一致。
