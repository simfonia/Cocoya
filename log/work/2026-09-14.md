## 修正：feature live 模式警示仍顯示 file 模式訊息（使用者回報）
- **根因**：`spec.js validate()` 只對影像類做 live 引導式豁免；feature（M4 前 file-only）落入表格類分支 → live 無欄位時顯示「尚未定義任何定義任何欄位（匯入 CSV/JSON）」error＋NO_LABEL／NO_FEATURES 警告。
- **修正**：新增 `isFeatureLive`（type=feature 且 data_source.mode=live）分支——無欄位無樣本時推引導式 warning（新鍵 `DSM_VALIDATE_NO_SAMPLES_FEATURE`，zh/en parity）；NO_LABEL／NO_FEATURES 豁免條件加 `!isFeatureLive`。feature 的 file 模式維持原 error（匯出必要條件不變）。
