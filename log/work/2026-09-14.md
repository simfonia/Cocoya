## Sidecar 啟動失敗友善提示（2026-09-14）
- **情境**：打包版在未設 Python 路徑（或缺 opencv-python）的機器上，sidecar 秒死 -> sidecar_send write stdin 得到 os error 232（管道正關閉中），使用者無從得知要設路徑。
- **修正三層**：
  1. Rust dataset.rs start_sidecar：含分隔符的 python_path 先驗證檔案存在；spawn 後 700ms try_wait 存活檢查，秒死即回 SIDECAR_START_FAILED 前綴錯誤（不再讓錯誤延後到 stdin write）。
  2. tauri.js _handleDatasetCommand：start_sidecar 後 re-ping 驗證真活著；啟動失敗統一 callback {success:false, errorCode:'SIDECAR_START_FAILED'}。
  3. sampler.js startCamera 記錄 state.lastCameraError；ui_layout onStartCamera 失敗時 showStatusMessage 友善提示（DSM_SIDECAR_START_FAILED，duration 0 不自動清除）；i18n 中英 parity 新增 DSM_SIDECAR_START_FAILED／DSM_SAMPLER_START_FAILED。
- **驗證**：cargo check 通過（僅既有 unused warning）、node --check 全過、DM 測試全套 fail 0、vite build OK。
